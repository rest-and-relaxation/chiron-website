# Chiron Global Tech — Homepage Concepts

Two homepage concepts prepared for client review.

## Structure

- `index.html` — selector page for repository and GitHub Pages use
- `site/index.html` — selector page used by the staging host
- `site/v1/` — Homepage V1
- `site/v2/` — Homepage V2
- `site/assets/` — shared font and imagery
- `site/vendor/` — shared animation library files

Each homepage is self-contained within its version folder, apart from the shared assets and vendor files.
